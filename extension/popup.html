WORKCODE Work Timer

Connected to

In WORKCODE open Monitoring (admins) → Create connection code, then paste it here.

What this extension sends to your company's WORKCODE server
  • the kind of page in front: WORKCODE, approved website, other website, or browser not in front
  • the name of the website only when it is on the approved list
  • whether the computer was used in the last 5 minutes
Never collected: page content, page titles, addresses of other websites, passwords, messages, history.
